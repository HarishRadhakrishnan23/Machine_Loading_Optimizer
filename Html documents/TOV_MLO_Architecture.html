preprocess.py — Data Pipeline (runs before every engine call)

1. Drop CYCLE_TIME = 0 rows (external vendors, missing CT)
2. Keep only operations in routing_master (v1: VB02–VB09 subset)

4. Compute Balance Qty = ORDERED − COMPLETED − REJECTED; drop if ≤ 0

ENGINE 1 — CP-SAT Scheduling Optimizer (Model B)

Scheduling unit: (PRODUCTION_ORDER, OPERATION_NO)

Time model: discrete (date, shift) slots · global slot index = 3·day + shift · NO minute axis

Variables: assign[t,m] (AddExactlyOne) · integer qty[t,m,slot] into capacity buckets

Capacity: Σ qty·CT + setup ≤ AVAILABLE_MINS per (machine, slot) · subsumes no-overlap

Precedence: start_slot(next) ≥ end_slot(prev) · skips non-routed ops

Batch rule: Stays on 1 machine · overflows to next OPEN shift (skip closed)

Setup time: Slot-granular · charged on ITEM_CATEGORY change, waived if carried over

Objective: Minimize weighted tardiness (days) + priority epsilon · integer-scaled

Output: Writes → schedule_output (offsets post-solve)

ENGINE 2 — Recommendation / Impact Engine

Trigger: Planner selects order(s) to elevate

Step 1: Snapshot schedule_output → old_completion_date

Step 2: Set elevated orders urgency_weight = 999999

Step 3: Re-run Engine 1 · time limit = 10s

Step 4: slip_days = new − old completion date per order
slack = CDD − new_completion_date

Classify: SAFE >5d · AT_RISK 0–5d · BREACH <0

Output: Writes → sim_results · Returns top-5 impacted

Critical Formulas & Decision Logic

Balance Qty (scheduling quantity)

balance_qty = QUANTITY_ORDERED
          - QUANTITY_COMPLETED
          - QUANTITY_REJECTED

Skip operation if balance_qty ≤ 0
Cascade: balance_qty of Op_n is
input quantity available for Op_(n+1)

Per (PRODUCTION_ORDER, OPERATION_NO) row in wip_orders

urgency_weight (Engine 1 objective)

pdd_score    = 1 / max(1, days_until_CDD)

ageing_score = (today - order_date).days
               / config.ageing_normalization_days

batch_bonus  = config.batch_bonus_value
               if days_until_CDD < batch_bonus_months*30
               else 0

urgency_weight = pdd_score
               + ageing_score
               + batch_bonus

Safety stock (CDD=NULL): urgency_weight = 0

batch_bonus_months editable via UI (config.json)

CP-SAT Objective Function (Model B)

completion_day = end_slot // 3
pdd_day        = (CDD - D[0]).days

Minimize:
  Σ urgency_s_i
    × max(0, completion_day_i - pdd_day_i)

+ Σ eps_s × (MACHINE_PRIORITY_j - 1)
    × assign_j

urgency_s = round(urgency_weight × 1000)
eps_s     = round(0.001 × 1000) = 1
(tiebreaker only — never overrides tardiness)

Integer-scaled (CP-SAT is integer-only). Queue-depth balance emerges from tardiness minimization.

Capacity Resolution

AVAILABLE_MINS (machine_master):
  = WORKING_MINS × OEE
  (use column directly when populated)

AVAILABLE_MINS (machine_daily override):
  = (WORKING_MINS - DOWNTIME) × OEE
  (use column directly when populated)

resolve_capacity():
  Start with machine_master baseline
  Override with machine_daily rows
  for matching machine_name + shift + date

Computed in memory only — never stored to Oracle

Batch Overflow Rule (Model B)

qty[t,m,slot] distributes the batch
across the assigned machine's OPEN
slots in [start_slot, end_slot].

Per (machine, slot) bucket:
  Σ qty·CT + setup ≤ AVAILABLE_MINS

Remainder spills to next_open(m,slot):
  smallest slot' > slot with cap > 0
  → closed slots (cap=0) are SKIPPED
  → spans arbitrarily many days

RULE: Batch never switches machine.
SETUP_TIME: charged at slot granularity.

Occupied slots = machine's open slots in [start_slot,end_slot] → contiguity for free

Engine 2 — Risk Classification

slip_days = new_completion_date
          - old_completion_date

slack     = CDD - new_completion_date

SAFE:    slack > risk_safe_threshold_days
AT_RISK: 0 ≤ slack ≤ threshold_days
BREACH:  slack < 0

Elevated order urgency_weight = 999999
Engine 2 time limit = engine2_time_limit_seconds
Return: top-5 orders by highest slip_days

risk_safe_threshold_days = 5 (configurable via config.json)

Time-Mapping — Model B (slot index)

slot = one (date, shift) pair
SHIFT_ORDER = [first, second, third]

slot_index(date, shift)
  = 3 × day_pos(date) + shift_pos(shift)

inverse:
  date  = D[slot_index // 3]
  shift = S[slot_index %  3]

cap[m,k] = AVAILABLE_MINS (machine, slot)
           cap = 0  ⇒  closed slot
next_open(m,k)= smallest k'>k, cap>0

Integer scale: TIME_SCALE=100 (mins),
               URGENCY_SCALE=1000 (weights)

Global, machine-independent index → precedence & tardiness correct across machines. No minute axis.
