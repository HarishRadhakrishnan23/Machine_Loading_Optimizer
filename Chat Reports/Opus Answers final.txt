  TOV Machine Loading Optimizer — Full Project Plan

  Vision & Mission

  Vision: Eliminate manual planning bottlenecks in Emerson's TOV valve shop floor with a fully automated, ML-driven scheduling system.

  Mission: Generate real-time, optimal shift-level schedules that minimize delivery tardiness, maximize machine utilization, and give
  planners instant "what-if" impact analysis when priorities change.

  Critical Formulas (locked)

  Balance Qty:
  balance_qty = QUANTITY_ORDERED − QUANTITY_COMPLETED − QUANTITY_REJECTED

  urgency_weight:
  pdd_score    = 1 / max(1, days_until_CDD)
  ageing_score = (today − order_date).days / config.ageing_normalization_days
  batch_bonus  = config.batch_bonus_value  if days_until_CDD < batch_bonus_months×30  else 0
  urgency_weight = pdd_score + ageing_score + batch_bonus
  Safety stock (CDD=NULL): urgency_weight = 0

  CP-SAT Objective:
  Minimize: Σ urgency_weight_i × max(0, completion_day_i − pdd_day_i)
          + Σ ε × (MACHINE_PRIORITY_j − 1) × is_assigned_j

  Batch overflow:
  qty_fits = floor(AVAILABLE_MINS / CYCLE_TIME)
  Remaining qty → same machine, next immediate shift

  Engine 2 risk:
  slip_days = new_completion_date − old_completion_date
  slack     = CDD − new_completion_date
  SAFE: slack > 5d | AT_RISK: 0–5d | BREACH: slack < 0
